Type any natural language UI description below. The AI adapter queries the model, receives structured JSON schemas, and dispatches real-time layout updates directly to active components.

Direct AI Model Integration Snippet

HTML & JS

Connect your custom LLM backend endpoint or client stream directly to the bridge: 

<!-- 1. Declare Gateway Component in Markup -->
<universal-ai-bridge
  endpoint="https://your-api.com/v1/ai/generate"
  target-component="saas-dashboard"
></universal-ai-bridge>

<!-- 2. Intercept AI Generation Complete Event -->
<script>
  document.addEventListener('ai-generation-complete', (e) => {
    const { prompt, payload, targetType } = e.detail;
    console.log('AI Generated Layout Payload:', payload);

    // Feed directly to engine component setters (Zero build tools)
    if (targetType === 'dashboard') {
      document.querySelector('universal-saas-dashboard').state = payload;
    }
  });
</script>

5. Schema-Driven Form

                  <universal-form>
                

                

                  Instantiate interactive forms purely from JSON schema arrays:
                

              

              

                
                
const form = document.querySelector('universal-form');
form.schema = [
  { name: "email", type: "email", label: "Email", required: true },
  { name: "role", type: "select", label: "Role", options: ["Admin", "User"] }
];

form.addEventListener('app-form-submit', (e) => {
  console.log('Form Output:', e.detail.formData);
});
