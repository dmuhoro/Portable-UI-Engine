1. CDN Single-Line Import

Include the unified barrel file and design tokens in any HTML document:

<link rel="stylesheet" href="./theme.css" /> <script type="module" src="./engine.js"></script>

2. Dynamic Theme Swapping API

Invoke the global controller to alter theme presets or override specific tokens:

// Switch to a pre-defined theme preset UniversalUI.setTheme('cyberpunk'); // Override custom design tokens directly UniversalUI.setTheme('dark', { '--color-primary': '#ff0055', '--radius-md': '12px' });

3. Deep State Mutation

Pass master state JSON objects to composite custom elements synchronously:

const dashboard = document.querySelector('universal-saas-dashboard'); dashboard.state = { metrics: [...], tableHeaders: [...], tableRows: [...] };
