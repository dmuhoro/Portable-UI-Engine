# Component Gallery (`apps/docs`) Specification

Please refer to the complete Phase 1 design composition specification at:
[`../../design/compositions/docs.md`](../../design/compositions/docs.md)

### Summary of Composition:
- **Purpose**: Component discovery, token inspection, and interactive state sandbox.
- **Breakpoints**: 320px (1-col mobile), 768px (2-col tablet), 1280px (3-col wide desktop).
- **Core Components**: `<ui-button>`, `<ui-input>`, `<ui-select>`, `<ui-checkbox>`, `<ui-dialog>`, `<ui-tooltip>`, `<ui-toast>`, `<ui-tabs>`, `<ui-menu>`.
- **Token System**: W3C Design Tokens consumed via CSS custom properties in Shadow DOM roots.
