# RUBRIC - Release Readiness

| Criterion | Threshold | Evidence Required |
|---|---|---|
| Gates | All pass locally and in CI | gate outputs |
| Build/pack/manifest | PASS | test outputs |
| Consumer proof | Next.js + HTML work | CI + evidence |
| Docs honest | No false claims | audit |
| Release hygiene | version/tag/changelog/release notes | git/gh |
| Security | no new high-severity in shipped deps | npm audit review |
