## Fixed

- **`parseKESInput` silently truncated malformed money (fail-open)** — `src/lib/money.ts`,
  commit `f64acc5` G. `'1.5.5'` parsed to 2, `'1-2'` to 1, `'15..5'` to 15 — rogue digits
  were dropped, so the wrong amount could reach the money path silently. Now the input must
  match `/^\d+(\.\d+)?$/` (no sign, no multiple dots), parsed with `Number()` not
  `parseFloat`, and **malformed input returns `null`** — the caller must surface the refusal,
  never a silent wrong number. 3 new cases in `money.test.ts`.
- **`check-i18n` hardcoded DYNAMIC_KEYS whitelist drifted (false positives)** —
  `scripts/check-i18n.ts`, commit `0af9d0f` G. The hand-maintained list silently missed
  `yes_set_q1..3` and reported real keys as unused. Now sourced by grep from the real render
  sites (`labelKey: "…"`, `\bid … key: "…"` in `OnboardingScreen.tsx`; receipt literals in
  `Receipt.tsx`); a sourced key missing from `sw.json`/`en.json` **fails the check** (exit 1).
